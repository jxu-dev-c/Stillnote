# Security reporting

Do not post credentials, private recordings, transcripts, or exploit details in public issues.
After publication, use GitHub's private vulnerability reporting on the repository Security
tab if enabled. If it is unavailable, open an issue requesting a private contact channel
without including sensitive details. Private reporting must be configured before release.

Stillnote 0.1.0 is experimental. Security fixes target the latest release.
Please provide the app/macOS versions, reproduction steps using synthetic data, and impact.
